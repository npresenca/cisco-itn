# 🌐 Projeto de Infraestrutura de Redes Corporativas (CCNAv7 ITN - SENAI)
Este projeto consiste em uma topologia de redes, desenvolvida em conjunto com o módulo: Introduction to Networks (ITN) do CCNAv7 no SENAI.

## 🚀 Escopo do Projeto & Arquitetura
Foi criado uma simulação de rede com filiais e provedores:
* Arquitetura de rede corporativa distribuída ligando filiais (SP/MG) através de múltiplos provedores de internet. Conectividade WAN.
* Configuração de ativos via CLI Cisco.
* Configuração de switches e CORES.
* Integração de infraestrutura cabeada para servidores, dispositivos e redes sem fio.

## ⌨ Comandos Aplicados
* Modos de acesso e configuração: ```enable, conf t, hostname, interface, ip address <ip> <mascara>```
* Comandos de diagnóstico: ```ping <ip>, traceroute <ip>```

## ✏ Testes
1. Analisar se o Cisco Packet Tracer está instalado na máquina.
2. Baixar o arquivo .pkt
3. Abrir o arquivo com o software.
4. Testar a rede com comandos de diagnóstico para analisar o tráfego.
